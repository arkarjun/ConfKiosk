# Tickets

Register attendees and manage check-in.

A standalone Google Apps Script project: registration form driven by
a Questions tab, ticket types, coupon codes (shared + batch), a
confirmation email with a self-generated QR code and a short
human-typeable check-in code, an admin page, and a manual check-in
page — no external services required.

**Status:** built and currently being tested locally. Code will be
pushed to this folder once testing is complete.
